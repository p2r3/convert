# Security Policy
Please do not open a public issue for security flaws, as this may expose the vulnerability to more people.
We will try and path the issue as fast as possible.

## Supported Versions

This project is currently using rolling releases.

## Reporting a Vulnerability

To report a vulnerability, please contact a lead developer directly. 

---EXAMPLE---
A bug that auto-runs files on the person's computer. This could be exploited by scammers just asking to convert a file.
