# Security Policy

## Supported Versions

The project is always rolling, only the latest version on the `master` branch is supported.

## Reporting a Vulnerability

Due of the nature of this project (browser + client side only), it is unusual for any security issues to be of any importance. 

Regardless, if you have found a vulnerability (most importantly code execution from input files), contact the current maintainer at contact@uwunya.org or the owner of the project at p2r3@p2r3.com. Low severity issues can be reported through github issues.
